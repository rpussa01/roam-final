# ROAM itinerary UI update

- Day view displays only one day at a time, with horizontally scrollable day navigation.
- Collapsed activity cards expand to show details and directions.
- Overview displays compact day summaries.
- Map view offers per-stop Google Maps links (not an embedded map).
- Previous / Next navigation.
- Existing itinerary generation, AI refinement, affiliate booking links, AdSense and infinite discovery are retained.

Note: Live API functionality and full production build were not verified in this environment.
